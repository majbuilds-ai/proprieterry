## Overview

A modern, high-conversion web experience designed for **proprieTerry Mortgage LLC**. The website combines an architectural, down-to-earth luxury aesthetic with transparent mortgage calculations and personalized advisory touchpoints.

### Key Highlights
- **Architectural Luxury Aesthetic**: Tailored typography, warm alabaster palettes, obsidian contrast, and custom brass accents.
- **Hero & Value Proposition**: Seamless brand crest integration, clear value drivers, and zero-distraction architectural imagery.
- **Interactive Payment Studio**: Real-time loan modeling for Purchase, Move-Up, and Refinance pathways with interactive sliders and live amortization breakdowns.
- **Terry AI Concierge**: Dedicated virtual loan advisor floating launcher for instant borrower guidance.
- **Direct Advisory Integration**: Simplified booking modal and direct contact channels to work one-on-one with Terry Shelton.
- **Netlify Form Integration**: Serverless form processing for consultation requests and intro call scheduling.

## Local Development

To run the site locally:

```bash
# Using Python
python3 -m http.server 8000

# Or using Node http-server / npx serve
npx serve .
```

Open `http://localhost:8000` in your browser.
